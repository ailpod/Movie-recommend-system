# 数据库数据同步说明

## 方法1：直接使用数据库文件（推荐）

现在 `Backend/Recommend.db` 文件已经添加到Git仓库中，克隆项目后可以直接使用。

## 方法2：使用数据导出/导入脚本

### 导出数据
```bash
cd Backend
python export_data.py
```
这会创建 `data_export.json` 文件，包含所有数据库数据。

### 导入数据
```bash
cd Backend
python import_data.py
```
这会从 `data_export.json` 文件恢复数据库数据。

## 使用场景

- **方法1** 适合数据变化不频繁的情况
- **方法2** 适合需要跨不同数据库系统迁移的情况

## 注意事项

1. 如果选择方法1，每次数据更新后需要提交数据库文件
2. 如果选择方法2，记得定期运行导出脚本并提交JSON文件
3. 两种方法可以同时使用，互为备份
